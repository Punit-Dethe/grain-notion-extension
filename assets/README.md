# Notion integration artwork

`notion.png` is the unchanged 192px light-theme icon from Notion's official
[developer documentation](https://developers.notion.com/guides/mcp/get-started-with-mcp),
downloaded on 14 October 2026 from its declared favicon:

https://developers.notion.com/mintlify-assets/_mintlify/favicons/notion-demo/1PaJq9z3waub4TpE/_generated/favicon/android-chrome-192x192.png

`media/icon.png` normalizes that square source to Grain's required 512×512 PNG
with proportional Lanczos sampling. The original source is 192px, not a newly
claimed high-resolution master; displayed icon sizes are smaller than it.
